# oneliner-gadget-roast

One line roasting a gadget used every day.

`main.ts` writes the line to `/output/entry.txt`:

> My smartwatch just congratulated me for standing up. My fitness goal is now officially 'vertical'.

## Run

    node main.ts

It writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set, else `/output/entry.txt`.
